# Burek / Burektech — retro-tech portfolio

Strona jest podzielona na osobne podstrony:

- `index.html` — start
- `about.html` — o mnie
- `tech.html` — technologie
- `collection.html` — pełna kolekcja komputerów
- `phones.html` — kolekcja telefonów
- `gallery.html` — galeria


Galeria:
- zdjęcia nie są już przycinane przez `object-fit: cover`;
- kliknięcie zdjęcia otwiera je w lightboxie;
- lightbox zachowuje proporcje i pokazuje możliwie duży obraz w jego naturalnej rozdzielczości;
- pod zdjęciem wyświetlany jest rozmiar w pikselach.

Języki: Polski, Bośniacki, Arabski.
